Surabaya Route Visualizer adalah aplikasi web interaktif yang dirancang untuk memvisualisasikan proses pencarian rute antar lokasi di wilayah Kota Surabaya menggunakan algoritma Breadth First Search (BFS).
Aplikasi ini dikembangkan sebagai bagian dari Tugas Besar mata kuliah Analisis Kompleksitas Algoritma.

Program ini tidak hanya menampilkan hasil akhir berupa rute terpendek, tetapi juga memperlihatkan bagaimana algoritma BFS bekerja secara bertahap melalui visualisasi pada peta nyata Surabaya.
Algoritma yang Digunakan

Aplikasi ini menggunakan Breadth First Search (BFS) dalam dua pendekatan:

1️⃣ BFS Iteratif
- Menggunakan struktur data queue
- Menelusuri node secara melebar level demi level
- Lebih efisien dalam penggunaan memori
- Cocok untuk implementasi sistem navigasi sederhana

2️⃣ BFS Rekursif
- Menggunakan pemanggilan fungsi berulang
- Bertujuan untuk menunjukkan pendekatan rekursif pada penelusuran graf
- Digunakan sebagai pembanding konsep terhadap versi iteratif
Kedua algoritma menghasilkan jalur yang sama, namun memiliki perbedaan dalam cara eksekusi dan struktur program.

Tujuan Pengembangan
- Tujuan utama dari pengembangan aplikasi ini adalah:
- Mengimplementasikan algoritma BFS dalam bentuk iteratif dan rekursif
- Membandingkan cara kerja BFS iteratif dan BFS rekursif
- Menyajikan hasil pencarian rute dalam bentuk visualisasi peta nyata
- Membantu pengguna memahami konsep graf, node, dan edge secara intuitif
